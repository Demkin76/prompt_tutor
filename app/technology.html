01 / DETERMINISTIC CORE⌁

The model does not own reality.

Movement, collisions, inventory and object state are simulated outside the LLM. Invalid actions simply cannot happen.

sim(state, action)
→ nextState
→ event[]
seed is the only randomness
02 / LIMITED PERCEPTION◌

Strong model. Incomplete world.

The challenge comes from partial information, resource limits and conflicting goals — not by deliberately making the model stupid.

Keymaster radius: 3 tiles
memory: significant events
map: hidden before lock
03 / VERIFIERS✓

Success is proven, not narrated.

Current levels use world predicates and event traces. The verifier replays actions through the simulation and checks the final state independently of the model.

goal: agent.pos == altar
trace: never(step.hazard)
replay: deterministic state check
04 / REPLAY↻

Every decision leaves a replay.

A replay stores the seed, charter, model decisions, actions and resulting states. Demos stay reproducible even if inference is unavailable.
